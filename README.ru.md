# astudio-marketplace-support — поддержка покупателей для продавцов Wildberries и Ozon

[English](README.md) · **Русский**

Автор: **astudio.one** — [astudio.one](https://astudio.one) · Лицензия: MIT · Версия 1.0.0

Плагин ведёт поддержку покупателей продавца на Wildberries и Ozon так, как это делал бы внимательный руководитель поддержки: отзывы, вопросы, чаты, возвраты и претензии — голосом бренда, по правилам площадок и закону о защите прав потребителей в редакции 2026 года. Каждый черновик проходит проверку, а всё, что публикуется, утверждает конкретный человек.

## Что умеет

- Голос бренда прежде всего: ни одного ответа, пока нет brand-voice.md
- Сортировка по правилам: здоровье, безопасность, контрафакт, угрозы судом и денежные споры всегда уходят человеку
- Ответы на отзывы по типам, ответы на вопросы только по данным карточки, ответы в чате площадки в окнах Ozon 48/72 часа
- Возвраты и претензии по ЗоЗПП с изменениями 2026 года (Постановление КС РФ 7-П, Постановление 657 вместо 2463) и калькулятор сроков
- Детерминированная проверка ответов на русском: контакты, ссылки, просьбы изменить оценку, обещания денег, медицинские утверждения, тон, длина
- Чтение очереди из API WB и Ozon только на чтение и публикация только того, что утвердил конкретный человек
- Еженедельная сводка: темы жалоб по товарам и что исправить в карточке

## Установка

В Claude Code:

```
/plugin marketplace add whoamnesia/astudio-marketplace-support
/plugin install astudio-marketplace-support@astudio-marketplace-support
```

Перезапустите Claude Code. Навыки появятся в меню `/` как `astudio-marketplace-support:astudio-marketplace-support` …

Установка на закреплённом коммите (так делает aiocenter.ru): склонируйте репозиторий, перейдите на опубликованный коммит и выполните `/plugin marketplace add ~/.aiocenter/packages/astudio-marketplace-support`.

Другие агенты (Cursor, Codex, Gemini CLI): каждый навык — обычный `skills/<name>/SKILL.md` со справочниками; укажите агенту папку или скопируйте её в правила агента.

## Навыки

| Навык | Что делает |
|---|---|
| `astudio-marketplace-support` | Главный навык: очередь → сортировка → черновик → проверка → согласование → публикация → выводы |
| `brand-voice` | Интервью или разбор прошлых ответов и файл brand-voice.md |
| `review-replies` | Ответы на отзывы по типам, пакетный режим, «что сделать кроме ответа» |
| `buyer-questions` | Ответы на вопросы по карточке только по фактам; «что добавить в карточку» |
| `buyer-chat` | Ответы в чате площадки, окна для ответа, снижение напряжения |
| `returns-claims` | Возвраты, споры с маркетплейсом и претензии поставщику по закону 2026 года |
| `escalation` | Приоритеты P1–P4 и записка для эскалации на один экран |
| `support-insights` | Еженедельный отчёт: темы, правки карточек, вопросы к поставщику |

## Инструменты

Python 3.9+, только стандартная библиотека. Читают то, что вы им передали, и ничего не записывают, если вы сами не перенаправите вывод.

| Скрипт | Назначение |
|---|---|
| `scripts/queue.py` | Чтение неотвеченных отзывов и вопросов WB и Ozon, только чтение |
| `scripts/route.py` | Сортировка по правилам, приоритеты и повторы по товарам |
| `scripts/reply_check.py` | Проверка ответа на нарушения правил площадок, корректно с кириллицей |
| `scripts/publish.py` | Отправляет только утверждённые и перепроверенные ответы; по умолчанию пробный прогон |
| `scripts/deadlines.py` | Сроки по закону о защите прав потребителей для дистанционной покупки |

## Безопасность

- Ничего не публикуется, не отправляется, не одобряется и не отклоняется без «да» конкретного человека; publish.py отказывается отправлять неутверждённое и заново проверяет текст.
- Для чтения очереди достаточно токена только на чтение; токены берутся из переменных окружения и не выводятся.
- Соблюдается лимит WB (1 запрос в секунду на категорию); ошибка 403 от Ozon объясняется как вопрос подписки.
- Справка по закону, а не юридическая консультация; споры решает человек.
